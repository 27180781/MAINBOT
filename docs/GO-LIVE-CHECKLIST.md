# רשימת בדיקה לפני עלייה לאוויר

עוברים על הרשימה מלמעלה למטה. כל סעיף שלא מסומן – עוצרים ומטפלים.

## שרת וסביבה

- [ ] Node 22 (‏`node --version`) או Docker מותקנים; `npm ci && npm run build` עוברים בלי שגיאות.
- [ ] `npm run typecheck` ו-`npm test` עוברים על הגרסה שנפרסת.
- [ ] יש דומיין שמצביע לשרת, ו-HTTPS פעיל (‏`curl -I https://<host>/health` מחזיר 200 עם תעודה תקינה).
- [ ] `PUBLIC_BASE_URL` זהה לכתובת הזו – `https`, בלי `/` בסוף.
- [ ] `NODE_ENV=production`, `TRUST_PROXY=true`, ו-`HOST=127.0.0.1` (או `ports: 127.0.0.1:3000:3000` ב-Docker) – פורט 3000 לא חשוף לאינטרנט.
- [ ] `.env` בהרשאות `600`, לא נמצא ב-git.
- [ ] התהליך רץ עם הפעלה מחדש אוטומטית (‏PM2 `pm2 save && pm2 startup`, או Docker `restart: unless-stopped`) ומופע **אחד** בלבד.
- [ ] ה-reverse proxy מאפשר כותרות/URL ארוכים (nginx: `large_client_header_buffers 4 128k;`) ו-timeout של 120 שניות לפחות.

## סודות וגישה

- [ ] `ANTHROPIC_API_KEY` תקין – בלשונית **בדיקה** ב-`/admin` הבוט עונה.
- [ ] `WEBHOOK_SECRET` אקראי וארוך (‏`openssl rand -hex 24`), לא "change-me".
- [ ] `ADMIN_USER` / `ADMIN_PASSWORD` חזקים; `/admin` מבקש סיסמה ומחזיר 401 בלי אחת.
- [ ] `ALLOWED_CALLER_PHONES` מכיל רק את המספרים הנכונים, לא `*`. בדקו את הרשימה גם ב-`/admin` → הגדרות (היא גוברת על `.env` אחרי שמירה).
- [ ] הוחלט אם צריך `BOT_PIN`; אם כן – הוגדר ונבדק בשיחה (כולל "קוד שגוי").
- [ ] "לבקש אישור מהמתקשר לפני פעולות כתיבה" מסומן ב-`/admin`.
- [ ] רשימת הכלים החסומים נבדקה מול `npm run mcp:tools` / לשונית חיבורים – מחיקות, פעולות המוניות והעברות כסף חסומות.
- [ ] שרתים שלא צריכים כתיבה מהטלפון מוגדרים `readOnly: true`.

## שרתי MCP

- [ ] `config/mcp-servers.json` נטען בלי שגיאה (בלוג: `MCP servers ready`).
- [ ] כתובות ה-URL של כל השרתים אמיתיות – אין `REPLACE-WITH-...` בקובץ; שרתים לא רלוונטיים מסומנים `"enabled": false`.
- [ ] בוצעה התחברות OAuth לכל שרת מ-`/admin` → חיבורים, וכולם במצב **מחובר** עם מספר כלים גדול מאפס.
- [ ] טוקני bearer (למשל `GITHUB_TOKEN`) נמצאים ב-`.env` אם השרת מופעל.
- [ ] `MCP_AUTH_DIR` (‏`.mcp-auth/`) נשמר בין הפעלות מחדש (volume / תיקייה קבועה) – הפעילו מחדש ובדקו שהחיבורים נשארו.
- [ ] `alwaysLoad` מכיל 3–6 כלים נפוצים לכל שרת, ולא יותר.
- [ ] בצ'אט הבדיקה: "מה יש בתיבת הפניות?" מחזיר נתונים אמיתיים מה-CRM; "תשלח וואטסאפ ל..." נעצר ומבקש אישור.

## הנחיות ופרומפט

- [ ] `config/instructions.md` מעודכן (מחירים, נקודות איסוף, כללי אישור) ונשמר ב-UTF-8.
- [ ] לשונית **פרומפט** מציגה את ההנחיות ואת רשימת השרתים המחוברים.
- [ ] ברכת הפתיחה והסיום נבחרו; הקול (Google חינם / Gemini בתשלום) הוחלט.
- [ ] `BOT_MODEL` ו-`BOT_EFFORT` נבחרו בהתאם לתקציב (ראו "עלויות" ב-README).

## המרכזייה (טכנוליין)

- [ ] נוצרה שלוחת API עם הכתובת מלשונית **חיבורים** (‏`https://<host>/pbx/technoline/<WEBHOOK_SECRET>`), שיטה GET.
- [ ] `curl` לכתובת עם `PBXcallId` ו-`PBXphone` מחזיר JSON עם הברכה ומודול `stt` (ראו README).
- [ ] `curl` לכתובת עם secret שגוי מחזיר 403.
- [ ] מספר / מקש בתפריט מנותב לשלוחה.
- [ ] `PBX_LONG_POLL_MS` נמוך מ-30000 (ברירת מחדל 20000).
- [ ] יש יתרת יחידות במרכזייה לזיהוי דיבור (0.25 יחידות ל-10 שניות).

## שיחת בדיקה אמיתית

- [ ] שיחה ממספר מורשה: שומעים את הברכה, שאלה פשוטה ("מה השעה?" / "מה יש בתיבה?") נענית.
- [ ] שאלה שדורשת כלים: שומעים "רק רגע" בזמן ההמתנה והתשובה מגיעה, בלי שהשיחה נופלת.
- [ ] פעולת כתיבה (מייל / וואטסאפ / עדכון): הבוט מקריא את הפרטים, מחכה ל"כן", ורק אז מבצע; "לא" מבטל.
- [ ] שתיקה פעמיים ברצף מסיימת את השיחה בנימוס.
- [ ] "תודה, זהו" מסיים את השיחה (הבוט נפרד ומנתק).
- [ ] שיחה ממספר **לא** מורשה נדחית ("המספר הזה לא מורשה") ומנותקת.
- [ ] אם הוגדר PIN: קוד נכון עובד, שלושה קודים שגויים מנתקים.
- [ ] בלשונית **שימוש וטוקנים** השיחה מופיעה עם תמליל, כלים ועלות.

## ניטור וגיבוי

- [ ] בדיקת uptime על `/health` (מחפשת `"ok":true`).
- [ ] רוטציית לוגים פעילה (pm2-logrotate / Docker `max-size`).
- [ ] סקריפט גיבוי יומי ל-`data/`, `.mcp-auth/`, `config/` ו-`.env` – מוצפן ומועתק לשרת אחר; בוצע שחזור ניסיון.
- [ ] ידוע מי מקבל התראה כששרת MCP עובר ל"נדרשת התחברות".
- [ ] נקבעה תקרת הוצאה חודשית בקונסולת Anthropic.

## אחרי השבוע הראשון

- [ ] נבדקו התמלילים: הבוט לא מבצע פעולות בלי אישור, לא ממציא מידע.
- [ ] עלות לשיחה תואמת את הציפייה; במידת הצורך הוחלף מודל / רמת מאמץ.
- [ ] כללים שחזרו על עצמם בשיחות נוספו כ"כללים קבועים" או ל-`instructions.md`.
- [ ] `alwaysLoad` עודכן לפי לשונית "לפי כלי" (הכלים שנקראים הכי הרבה).
